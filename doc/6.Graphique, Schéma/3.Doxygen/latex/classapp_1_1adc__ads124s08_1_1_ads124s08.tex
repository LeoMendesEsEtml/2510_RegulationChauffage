\doxysubsection{Description détaillée}
Driver pour l\textquotesingle{}ADC ADS124\+S08 avec interface SPI. 

Cette classe encapsule toutes les fonctionnalités nécessaires pour communiquer avec l\textquotesingle{}ADC ADS124\+S08 via SPI en mode 1.\+0. Supporte la configuration automatique, la mesure de résistance et la conversion en température.

\begin{DoxyNote}{Note}
L\textquotesingle{}ADC doit être connecté via SPI1 et le signal DRDY sur GPIO. 
\end{DoxyNote}

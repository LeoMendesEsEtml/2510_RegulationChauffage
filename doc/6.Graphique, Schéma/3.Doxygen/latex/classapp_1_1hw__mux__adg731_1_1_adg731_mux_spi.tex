\doxysubsection{Description détaillée}
Pilote SPI pour multiplexeurs ADG731. 

Classe pour contrôler jusqu\textquotesingle{}à 4 multiplexeurs ADG731 via l\textquotesingle{}interface SPI0. Chaque multiplexeur peut gérer 32 canaux. Configure automatiquement les paramètres SPI optimaux et gère la communication avec les circuits.

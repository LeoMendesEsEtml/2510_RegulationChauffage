# 2510_RegulationChauffage
Ton projet consiste à développer une solution électronique dédiée, basée sur un Raspberry Pi CM5 et des cartes spécifiques, permettant de remplacer un automate coûteux pour réguler un chauffage en simulant des sondes résistives à partir de données météorologiques et de mesures réelles, tout en publiant les informations sur un service cloud

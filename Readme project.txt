nom du projet : RegulationChauffage
no de projet  : 2510 
date          : 22.09.2025

explicatif du projet:
---------------------
Développement d’un système de régulation de chauffage basé sur Raspberry Pi CM5, 
intégrant des cartes électroniques dédiées pour la lecture et la simulation de sondes résistives, 
l’exploitation de prévisions météo via API et la publication des données sur le cloud.
